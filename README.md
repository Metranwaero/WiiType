# WiiType 1.0.0 [Official Repository]
# What is WiiType? 
WiiType 1.0.0 is a proprietary software application developed for the Nintendo Wii. It allows users to write text documents in .txt format and save them locally to an SD card, without requiring an internet connection.

Its visual interface is inspired by 1990s BIOS menus.
# Features
- Local File Storage — Save documents locally to an SD card.
- Arimo Font — Uses Arimo, a typeface metrically compatible with Arial.
- File Management — Open saved notes, create copies, and delete files.
- On-Screen QWERTY Keyboard — Features an on-screen QWERTY keyboard adapted for the Nintendo Wii.
# Installation
1. Download **WiiType 1.0.0** from the [Releases](../../releases) section.
2. Extract the folder from the ZIP archive.
3. Move the WiiType folder to the apps folder on your SD card.
Recommendation: If the Homebrew Channel is not installed on your Nintendo Wii, you can get it from the [official Homebrew Channel website](https://hbc.hackmii.com/)
